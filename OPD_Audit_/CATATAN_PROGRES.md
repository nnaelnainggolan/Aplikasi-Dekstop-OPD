# Progres v2.0
Dibangun untuk permintaan empat pembaruan. Aturan gambar diperbaiki berdasarkan format template yang tersedia dan pengujian geometri lokal. Belum menerima workbook 07 September yang semua slotnya ditandai perlu dicek, sehingga perbaikan pada seluruh koleksi pengguna belum dapat dipastikan. Gunakan alasan/pratinjau untuk pemeriksaan lanjutan.
Pengujian: anchor bergeser, dua area, gambar ganda, slot kosong, tanggal inklusif, file tanpa tanggal, file rusak, sumber tidak berubah, dan pembacaan ulang ekspor Excel. Pengujian popup pada Windows pengguna masih diperlukan.
